# Python メモ帳

画面はMaterialize 1.0.0によるマテリアルデザインです。CSS・JavaScriptを同梱しているため、外部CDNへの接続なしで使えます。MaterializeのMITライセンスは `notepad/dist/vendor/LICENSE.materialize` に収録しています。

Python 3.10以上で `python app.py` を実行すると、ブラウザで http://127.0.0.1:8765 が開きます。
追加パッケージは不要です。終了はターミナルで Ctrl+C を押します。
ポートを変える場合は `python app.py --port 8766` を使います。

Windowsでは `start.cmd` のダブルクリックでも起動できます。この端末ではCodex同梱のPythonを使用します。

Chromeを指定して起動する場合は `start-chrome.cmd` をダブルクリックします（`python app.py --browser chrome` も使用可能）。`start.cmd` は従来どおり既定のブラウザで開きます。

- 左側：作成日、改行してタイトルの一覧
- 起動・画面読み込み時に `data/memos/` 直下の `.txt` を自動検出して一覧表示。直接追加したファイルも、ファイル名をタイトルとして表示します
- ゴミ箱内のファイルは「ゴミ箱」に表示。既存メモの日付・タイトルは保持し、初めて検出したファイルの日付にはファイルの作成日時を使用します
- 右側：タイトルとメモ本文の入力欄
- 「グループ作成」でグループ名と同じサブフォルダーを `data/memos/` 内に作成。各グループの鉛筆アイコンで名前とフォルダー名を変更できます
- メモ編集欄の「グループ」で所属を変更すると、ファイルも移動します。新規追加・ドロップ取り込みは選択中のグループに保存します
- 一覧モードではグループ名をクリックして開閉。付箋モードでは左のグループ一覧から表示対象を選択します
- 一覧のメモはグループ名より一段字下げして表示。メモをグループ名へドラッグ＆ドロップすると、ファイルごと移動します（付箋モードでは左のグループ一覧へドロップ）。閉じたグループにも移動できます
- 既存の直下のメモは「未分類」として表示。グループ内のメモも起動時に検出し、ゴミ箱からは元のグループへ復元します
- 上部の「一覧／付箋」で表示を切り替え。付箋には日付・タイトル・本文の冒頭を表示し、選択すると編集できます。表示モードはブラウザに記憶します
- 付箋モードは最初に全幅で表示。付箋をクリックすると右半分に入力エリアが開き、「× 閉じる」で付箋の全幅表示に戻ります。閉じても入力内容は保持され、自動保存は続きます
- 「新規追加」：新しいメモを追加
- `.txt` ファイルを画面にドラッグ＆ドロップすると、ファイルごとにメモを追加（複数選択可）
- 取り込み時のタイトルはファイル名（末尾の `.txt` を除く）、本文はファイル全体
- UTF-8、BOM付きUTF-16、Shift_JISの読み込みに対応。元ファイルは変更しません
- メモごとに `data/memos/タイトル.txt`（UTF-8）へ本文を自動保存
- タイトル変更時はファイル名も変更。同じタイトルは `タイトル (2).txt` のように区別
- 一覧の各メモ右側のゴミ箱アイコンで、ファイルを `data/memos/ゴミ箱/` に移動
- 左側の「ゴミ箱」で削除済みメモを表示。各行のゴミ箱アイコンで、確認後にファイルを完全に削除します
- ゴミ箱一覧の復元アイコンでメモを保存フォルダーに戻します。同名ファイルがある場合は連番を付けて上書きを防ぎ、復元したメモを開きます
- ファイル名に使えない記号は `_` に置換。空のタイトルは `無題のメモ.txt`
- 日付・並び順などの管理情報は `data/notes.json` に保存（本文は含みません）
- 以前の一括保存データは起動時に自動移行し、元のファイルを `data/notes.json.bak` に保管

配信・読み込み・検証・ファイル保存はPython標準ライブラリで実装しています。ブラウザ画面の表示にはHTML・CSS、入力とPythonへの通信にはJavaScriptを使用します。

HTMLファイルを直接開かず、Pythonから起動してください。以前のブラウザ保存版のメモは自動移行されません。
